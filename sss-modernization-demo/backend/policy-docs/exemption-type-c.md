# Exemption Type C: documented hardship

Type C is the hardship exemption. Unlike Types A and B it is never decided by a rule alone, because a person has to look at the evidence.

## Who is considered
A registrant is considered for Type C when the profile says they have documented hardship. The system then sets the Type C result to Pending Review, with the reason that a caseworker must review it. The system never sets Type C to Eligible by itself. Without documented hardship on the profile, the result is Not Eligible.

## Caseworker review: how Type C is decided
A case manager reads the hardship evidence and decides the case as Approved or Denied. Pending Review does not mean approved. A registrant can apply for Type C while the result is Pending Review. A Denied decision always records a reason and can be appealed.

## Hardship evidence
An approval of a Type C case needs hardship evidence on file. The registrant attaches it to the case as a document link of the type hardship evidence. The decision controls check for it at the moment of approval. An approval without hardship evidence fails the supporting evidence control and opens a compliance review.

## What counts as hardship
The demo does not define hardship in detail. The profile only records whether the registrant has documented hardship, yes or no. The case manager judges the evidence that was attached to the case.
