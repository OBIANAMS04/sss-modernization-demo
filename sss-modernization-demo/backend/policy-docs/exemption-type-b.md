# Exemption Type B: income under $20,000

Type B is the income-based exemption for low-income registrants. It depends on the annual income on the registrant's profile.

## Who qualifies: the income limit
A registrant qualifies for Type B when the annual income on the profile is below $20,000. An annual income of $20,000 or more does not qualify. The income is a whole number of dollars. If no annual income is on file, the result is Not Eligible and the reason asks the registrant to add it to the profile.

## How eligibility is decided
The system decides Type B automatically, in the same way as Type A. The rule is run again each time the profile is saved and each time the registrant selects Check Eligibility. The reason says whether the income is below the $20,000 threshold or at or above it. It does not repeat the exact income.

## Income statement
An approval of a Type B case needs an income statement on file. The registrant attaches it to the case as a document link of the type income statement. The decision controls check for it at the moment of approval. An approval without an income statement fails the supporting evidence control and opens a compliance review.

## Changing the income
A registrant who changes the annual income on the profile gets a fresh Type B result straight away. A decision has to rest on a result that is newer than the last profile change. If the profile changed after the last check, the control for accurate and timely records fails.
