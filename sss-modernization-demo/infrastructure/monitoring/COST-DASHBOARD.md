# #26: Cost Monitoring Dashboard

Real-time cost tracking with daily/monthly/yearly views.

**Widgets:**
- Daily spend ($)
- Month-to-date vs budget
- Cost by service (ECS, RDS, ElastiCache, ALB, S3)
- Reserved instance utilization
- Savings opportunities
- Forecast vs actual
- Top cost drivers

**Alerts:**
- Budget threshold exceeded (>90%)
- Anomaly detection (30% increase)
- Unused resources (unattached volumes, idle instances)

**Reports:**
- Daily cost summary (email)
- Weekly trend analysis
- Monthly optimization recommendations
