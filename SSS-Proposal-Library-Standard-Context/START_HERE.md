## The 3-Step Deployment

If you're using GitHub Pages:

```bash
# 1. Initialize git
git init

# 2. Commit everything
git add .
git commit -m "SSS Proposal Library"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/sss-proposal-library.git

# 3. Push to GitHub
git push -u origin main
```

Then **Settings → Pages → Deploy from main branch**.

**Wait 1–2 minutes. Your site is live.**
