## PREP-1 hand-in: project introduction (about 90 seconds spoken)

I am OBI. This is a Colaberry rehearsal case study: a modernization of Selective Service systems, built on synthetic data.
It is not connected to the real Selective Service System, and the proposal behind it was never submitted.

It helps four groups of people. Citizens register, check whether they qualify for an exemption, apply, and see the reason
for every decision. Case managers get one queue and automatic checks. Administrators give and remove access, with a
reason, in the app. Leadership sees totals and trends, with no personal data. Every action goes in an audit log that the
database itself will not let anyone change.

There is a cost I can point to. The hosted site was retired on 6 November 2026, so the running cost is now zero. While it
ran, the database cost six dollars a month, and the last charge was one dollar twelve. It still runs locally from the
public repository: forty-six stories in four releases are addressed, and seventeen hundred and thirty-seven tests passed
from a fresh copy.

People still decide what matters. Every exemption, every denial and every override is a person's decision. The assistant
answers policy questions from synthetic documents, with citations, and it never decides eligibility.

The real next work is plain. A hands-on screen-reader test and an independent security test are both still not done.
Colaberry's attention now moves to the Crash Records project. Thank you.
