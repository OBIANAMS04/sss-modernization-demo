Access rules change without a release

  • Open Policy Agent decides every request.
  • Admins switch rules, with a reason.
  • Refusals are logged with the rule.
Scene 16, API access policies (STORY-016). Every request is decided by Open Policy Agent before it reaches the application: the rules check the role, the kind of record, the action and the record's owner or assignee, such as 'case managers can view and work cases assigned to them'. An administrator changes a rule here with a reason; it applies at once, every version is kept, and each refusal is in the audit log with the rule behind it. The policy can only narrow what the application allows. We also found that an earlier 'governance' component claimed to enforce such policies but never called OPA; it was removed.
