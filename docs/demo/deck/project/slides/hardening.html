  • Sign-out ends the session.

Scene 24, security testing and hardening (STORY-041). An attack suite of 52 checks tries sign-in bypass and token tampering, reading other people's records, SQL and script injection, password guessing, and checks the security headers; all pass. Signing out now ends the session on the server, sign-in and registration are throttled, response time no longer reveals whether an address is registered, and every page carries a content security policy. People who turn on two-step verification get ten one-time recovery codes, shown once. This is the team's own testing; an independent penetration test is still owed before real data.
