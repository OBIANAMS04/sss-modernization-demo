Quality is watched after go-live

  • Nine signals, week against month.
  • A fixed test set against a baseline.
  • Drift alerts the administrators.
Scene 19, drift detection (STORY-021). The AI Quality page tracks nine signals from real answers, such as the grounded rate, how often answers are withheld, latency and negative feedback, and compares the last seven days with the 28 before, each with a tolerance and a minimum sample. An administrator can re-run the 33-question golden set on the server; a run below a threshold, or more than five points under the baseline, is drift, and drift alerts the administrators and the audit log. A change of model or of the policy documents is marked on the trend. This screen is the real run on the demo deployment: 100% on all four measures, now the baseline. Its first run had found answers that opened with an uncited sentence, which the check rightly withheld; the instructions to the model were fixed and the run passed.
