Scene 11, accessibility (STORY-011, Section 508). Every page is checked against WCAG 2.1 AA, which includes the Section 508 standard, signed out, as an applicant and as a case manager. An automated audit runs in Chrome: every WCAG A and AA rule in axe-core, a keyboard pass that reaches every control with visible focus and a skip link first, page titles and landmarks, nothing lost at 320 pixels wide, and how errors are announced. Run on the code before this work it failed every page: tabs titled "frontend", fields named by their placeholders, low-contrast green, no skip link, errors never announced. All twelve page and role combinations pass now. Three criteria tools cannot test were also fixed: a warning two minutes before a session ends with Stay signed in, form borders with 3:1 contrast, and a confirmation before an application or appeal is sent. Shown here: registration after an empty submit; each field is marked invalid with its message, and focus is on the first one. A hands-on audit with JAWS, NVDA and VoiceOver is planned for R3. Demonstrated on a synthetic demo deployment.
