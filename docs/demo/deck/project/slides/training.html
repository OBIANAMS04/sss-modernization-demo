Demo · Scene 25

Staff trained in the app

  • Modules for each staff role.
  • Answers graded on the server.
  • Progress visible to administrators.
Scene 25, staff training (STORY-035). Case managers, administrators and leadership each get short modules built from screens of the real pages, ending in a four-question knowledge check. The answers stay on the server, which grades each attempt, three of four to pass, and records it, so a pass cannot be claimed from the browser. When a module changes, staff must pass it again. Administrators see the whole team's progress.
