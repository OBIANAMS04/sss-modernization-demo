Every request can be traced

Scene 21, observability (STORY-026 to 029). Every request, database query and Claude call is traced with OpenTelemetry; each response, log line and audit entry carries its trace id, and no question text or personal data is recorded. Latency and errors are measured per route, and every AI call's tokens and estimated cost. Service objectives, availability 99.5%, 95% of requests under two seconds, errors under 1%, AI spend under the daily budget, plus the drift and fairness checks, are evaluated every minute; a breach opens an alert for administrators with a runbook entry and closes when it recovers. This screen comes from a test run with deliberate server faults. Export to Datadog or any OpenTelemetry backend is one setting; without it, nothing leaves the server.
