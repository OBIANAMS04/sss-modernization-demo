Demo · Scene 12

Staff access is granted, not claimed

  • A case manager gives access in the app, with a reason.
  • Never your own access, never the last case manager.
  • Every change is logged, and the person is told.
Scene 12, Staff Access. Case-manager access is given in the app by an existing case manager, with a required reason; registering an address no longer makes anyone staff. Before this change, an address on a configuration list became staff for whoever registered it first. Nobody can remove their own access or the last case manager's, and a database lock stops two managers removing each other at the same moment. Every grant and removal is written to the Security Audit Log in the same transaction, and the person is notified. Here Dana Whitfield has given Sam Ortiz access. A production system would also keep grants to an administrator or a second approver.
