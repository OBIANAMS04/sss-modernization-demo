Denials always give a reason

  • A case manager cannot deny without a written reason.
  • The applicant sees that reason on the case timeline.
  • One click appeals the decision and sends it back for review.
Scene 4: Taylor Brooks's Type A application was denied by Sam Ortiz with the reason "Proof of age was not provided." The system will not save a denial without a reason, and the applicant sees it on the timeline. This meets the Administrative Procedure Act's requirement to state the grounds for a denial. From the same page the applicant can appeal, which sends the case back to a case manager.
