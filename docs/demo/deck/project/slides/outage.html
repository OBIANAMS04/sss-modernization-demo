Stays up when the database goes

  • Answers "try again", saves nothing.
  • Recovers by itself, no restart.
  • Checked from outside every 30 minutes.
Scene 23, resilience (STORY-034 and 036). If the database becomes unreachable, the API keeps running, answers every data request with a clear 503 and a retry time, and saves nothing half way; when the database returns it recovers by itself without a restart. The drill passes 22 of 22 checks. An uptime check outside the hosting platform runs every 30 minutes and opens an issue on failure. The multi-region production design, AWS GovCloud with database failover between two regions, is written and waits on approval.
