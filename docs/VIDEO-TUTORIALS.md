- Need troubleshooting skills

## Video Production Standards

### Quality Requirements
- **Resolution:** 1080p minimum (1440p preferred)
- **Frame rate:** 30 fps or 60 fps
- **Audio:** Clear narration, background music optional
- **Captions:** Required in English and Spanish
- **Duration:** 2-5 minutes for short videos, 5-10 for medium, 10-20 for detailed

### Hosting Platforms
1. **YouTube** - Public videos, playlist organization
2. **Internal Wiki** - Embedded with documentation
3. **Email** - Links in notification emails
4. **Mobile App** - Built-in video player

### Accessibility
- Auto-captions + human-reviewed captions
- Audio descriptions for visual elements
- High contrast text overlays
- Keyboard navigation for video players
- Transcript provided for all videos
- Spanish subtitles required

### Analytics Tracking
- View counts per video
- Completion rate
- Dropout points
- User demographics
- Search terms leading to videos
- Feedback/comments moderation

### Update Schedule
- New feature videos: Released with feature
- Process changes: Updated within 1 week
- Quarterly review: Q1, Q2, Q3, Q4
- User feedback: Incorporate suggestions
